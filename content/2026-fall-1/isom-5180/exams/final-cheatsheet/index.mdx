## 1. 定义速查 Definitions（课件原文 ↔ 中文）

### 1.1 Module 1 · 网络、OSI、设备

| Term | English（slides） | 中文 |
|---|---|---|
| End devices | Where a message **originates from** or where it is **received** | 终端设备：消息的起点或终点（PC、服务器、打印机） |
| Intermediary devices | **Interconnect** end devices; regenerate and retransmit signals, maintain information about pathways, notify other devices of errors | 中间设备：把终端连起来（switch、router、AP、firewall） |
| Network media | The medium that allows a message to travel from source to destination: copper (electrical impulses), fiber (pulses of light), wireless (electromagnetic waves) | 网络介质：铜线电脉冲、光纤光脉冲、无线电磁波 |
| LAN | Interconnects end devices in a **limited area**; administered by a **single organization or individual**; **high-speed** bandwidth | 局域网 |
| WAN | Interconnects **LANs** over **wide geographical areas**; administered by **one or more service providers**; slower links | 广域网 |
| Internet | Worldwide collection of interconnected LANs and WANs; **not owned by any individual or group** | 互联网 |
| Intranet | Private collection of LANs and WANs **internal to an organization**, accessible only to members or others with authorization | 内联网：只给内部 |
| Extranet | Secure access for individuals who **work for a different organization** (suppliers, customers, collaborators) | 外联网：有控制地给外部组织 |
| Confidentiality · Integrity · Availability | Only intended recipients can read the data · data has not been altered during transmission · timely and reliable access for authorized users | 机密性 · 完整性 · 可用性 |
| Bandwidth | Amount of information that can flow through a network connection in a given period of time (bps) | 带宽 |
| Protocol | A set of rules for communication; each protocol defines a small part of what the network does | 协议 |
| Layered model benefits | Reduces complexity · standardizes interfaces · modular engineering · interoperable technology · accelerates evolution · simplifies teaching and learning | 分层的 6 个好处 |
| Encapsulation | Lower layers put the **PDU from the upper layer into their data field** and **add headers and trailers** | 封装 |
| De-encapsulation | The receiving layer **reads the control information** from its peer layer, **strips it**, and passes the data up | 解封装 |
| PDU | Protocol data unit: Data → **Segment** (L4) → **Packet** (L3) → **Frame** (L2) → **Bits** (L1) | 各层数据单元 |
| FCS | Frame Check Sequence in the frame **trailer**; receiver recalculates — mismatch → **discard** | 帧校验序列（L2 检错） |
| Repeater | Regenerates a degraded signal as clean 1s and 0s; extends LAN distance; **Layer 1** | 中继器 |
| Hub | **Multiport repeater**, Layer 1, network concentration point; sends bits out **all other ports** | 集线器 |
| Switch | **Layer 2** device creating LAN segments, **each a separate collision domain**; **filters traffic by MAC address** | 交换机 |
| MAC address table | = switching table = **CAM table**: **MAC address · Port · Time stamp**, learned dynamically | MAC 地址表 |
| Flood / Forward / Filter | Unknown or broadcast destination → all ports except incoming · known on another port → that port only · known on the incoming port → do not forward | 泛洪 / 转发 / 过滤 |
| Microsegmentation | Each host gets the medium's **full bandwidth** on its own port | 微分段 |
| Full duplex | Send and receive **at the same time** | 全双工 |
| Buffering | Frames to the same destination are **held in memory** and forwarded **one at a time** | 缓冲 |
| Collision domain / Broadcast domain | Devices whose simultaneous sends collide / devices reached by a broadcast | 冲突域 / 广播域 |
| Router | **Layer 3** device; uses the **logical (network-layer) address**; can connect different Layer 2 technologies; examines the packet, chooses the best path, switches it to the proper port | 路由器 |
| Routing table | Destination **network → outgoing interface** (+ next hop, metric, source) | 路由表 |
| MAC address | **48 bits = 12 hex digits**; first 3 bytes = **OUI** (vendor), last 3 bytes assigned by the vendor | MAC 地址 |
| Unicast / Broadcast / Multicast | One to one (predominant) · one to all, universal broadcast address · one to a specific group | 单播 / 广播 / 组播 |

### 1.2 Module 2 · IP 地址、解析、路由

| Term | English（slides） | 中文 |
|---|---|---|
| IPv4 address | **32-bit** number in dotted decimal, four **octets** (0–255); unique within a network | IPv4 地址 |
| Network / Host portion | High-order bits identify the **network**; low-order bits identify the **device** on it | 网络部分 / 主机部分 |
| Interface addressing | A device does not have an address; **each of its interfaces** has one | 地址属于接口 |
| Classes A–E | Leading bits 0 / 10 / 110 / 1110 / 1111 → first octet 1–126 / 128–191 / 192–223 / 224–239 / 240–255 | 地址分类 |
| Network address | **All zeros in the host portion**; represents the entire network | 网络地址 |
| Broadcast address | **All ones in the host portion**; every host on that network | 广播地址 |
| Host address | Any address that can be assigned to an interface | 主机地址 |
| Loopback | 127.0.0.1 — tests the local TCP/IP stack | 回环地址 |
| Public address | **Unique** on the Internet; assigned by registries / ISPs | 公有地址 |
| Private address | 10.0.0.0/8, 172.16.0.0–172.31.255.255, 192.168.0.0/16; **Internet routers discard them** | 私有地址 |
| NAT | Translates **private addresses to public** addresses; a company uses a few registered addresses instead of a whole network | 网络地址转换 |
| PAT | Translates **port numbers** as well, so **one public IP** serves many private hosts | 端口地址转换 |
| Static addressing | Manually configured; for devices others must find (servers, printers, routers) | 静态分配 |
| DHCP | Server **leases** an address from a pool with mask, default gateway and DNS; preferred for large networks | 动态主机配置 |
| DORA | **Discover** (broadcast) → **Offer** (unicast) → **Request** (broadcast) → **Ack** (unicast) | DHCP 四步 |
| DNS | Resolves a **name to an IP address**; local → root → top-level domain → second-level domain servers | 域名系统 |
| ARP | Resolves a known **IP address to a MAC address** on the same LAN; request broadcast, reply unicast | 地址解析协议 |
| ARP table | **IP ↔ MAC** of devices on the same LAN; dynamic, entries time out (OS-dependent) | ARP 表 |
| Default gateway | The **IP address of the router interface** that connects to the source host's segment; **must be in the same network segment** as the host | 默认网关 |
| Path determination | Comparing the destination address with routes in the routing table to choose the **best path** | 选路 |
| Next-hop router | The router a packet is sent to for a network that is not directly connected | 下一跳 |
| Routed protocol | Carries user data and can be forwarded by routers (IP, IPX, AppleTalk) | 被路由协议 |
| Routing protocol | Routers exchange routing information to build tables (RIP, IGRP, EIGRP, OSPF); **routing protocols determine the path routed protocols follow** | 路由协议 |
| Connected / Static / Dynamic route | Directly attached network (C) · entered manually by the administrator · learned by a routing protocol, adapts to changes | 直连 / 静态 / 动态路由 |
| Metric | Value that rates a route: **RIP = hop count**; IGRP / EIGRP = bandwidth, delay, load, reliability (default bandwidth + delay) | 度量值 |

### 1.3 Module 3 · 传输层

| Term | English（slides） | 中文 |
|---|---|---|
| Transport layer services | **Segmenting**; **end-to-end** operations; host-to-host delivery; **reliability** (sequence numbers + acknowledgments); **flow control** (sliding windows) | 传输层 5 个功能 |
| Connection-oriented | Requires an **exchange of messages before data transfer** (TCP) | 面向连接 |
| Connectionless | No exchange of messages and no pre-established correlation (UDP) | 无连接 |
| Three-way handshake | SYN (SEQ x) → SYN-ACK (SEQ y, ACK x+1) → ACK (SEQ x+1, ACK y+1); synchronizes **initial sequence numbers** and ports | 三次握手 |
| ISN | Initial sequence number, a **random** number chosen by each host | 初始序列号 |
| Sequence number | Numbers the data so segments can be **reordered** and gaps detected | 序列号 |
| Acknowledgment number | **Expectational (forward) acknowledgment** — the **next number expected** | 确认号 |
| Window size | Amount of data that can be sent **before an acknowledgment is required** (max unacknowledged bytes outstanding); larger = more efficient; **variable** | 窗口大小 |
| Sliding window | The window moves forward with each ACK and grows or shrinks with network performance | 滑动窗口 |
| Retransmission | Sender starts a **timer**; if no ACK before it expires, **retransmit** (and slow down) | 超时重传 |
| Port number | Passes data to the right **application**; tracks different **conversations** at the same time | 端口号 |
| Well-known / Registered / Dynamic | **0–1023** servers · **1024–49151** user applications · **49152–65535** client connections | 三种端口范围 |
| Multiplexing | One host holds many conversations, each with its **own port number** | 多路复用 |
| TCP vs UDP | TCP: windowing, connection-oriented, error recovery, segmentation, in-order · UDP: none of these · **both use port numbers** | 两种传输协议 |

### 1.4 Module 4 · 子网

| Term | English（slides） | 中文 |
|---|---|---|
| Subnetting | Segmenting a network into multiple smaller network spaces called **subnetworks** | 子网划分 |
| Subnet field | Bits **borrowed from the host portion** (starting at the leftmost host bit) | 子网位 |
| Subnet mask | Determines which part of an address is network (+ subnet) and which is host: **N and S bits = 1, H bits = 0** | 子网掩码 |
| Slash format | /n = number of 1s in the mask | 斜杠写法 |
| Formulas | **Subnets = 2^s** (s = bits borrowed) · **Hosts = 2^h − 2** (h = host bits remaining) · **N + S + H = 32** | 公式 |
| Requirements | **Number of subnets** → minimum bits to borrow · **number of hosts** → maximum bits; plan for the **largest** subnet and allow for growth | 按需求规划 |
| Maximum bits | Class A 22 · Class B 14 · Class C 6 (leave 2 host bits) | 最多可借 |
| ANDing | Binary process by which the router calculates the **subnetwork ID**: address AND mask (1 AND 1 = 1, else 0) | 按位与 |

## 3. 题型 → 解法 Typical questions

### 3.1 给地址求 Class / network / broadcast

1. 第一个 octet 定 Class → 标出 N / H（A N.H.H.H · B N.N.H.H · C N.N.N.H）。
2. H 全写 0 → **network**；H 全写 255 → **broadcast**；中间是可用主机，数量 2^h − 2。

> 130.6.8.9 → B → network 130.6.0.0，broadcast 130.6.255.255，可用 130.6.0.1 – 130.6.255.254。

### 3.2 借 n 位 → 掩码、子网数、主机数、列子网表

1. /n = 默认位数 + 借的位数 → 掩码（关键段：128 · 192 · 224 · 240 · 248 · 252 · 254 · 255）。
2. 子网数 **2^s**；每子网主机 **2^h − 2**。
3. 间隔 = **256 − 关键段的掩码值**，在关键段上每行加间隔。
4. 每行：Network = 这个数；Broadcast = 下一行 − 1；Range = Network + 1 到 Broadcast − 1。

> 192.15.22.0 借 4 位 → /28，255.255.255.240，16 个 × 14 台，间隔 16：.0（.1–.14，bc .15）、.16（.17–.30，bc .31）……
> 130.12.0.0 借 6 位 → /22，255.255.252.0，第 3 段间隔 4：130.12.0.0（0.1 – 3.254，bc 3.255）、130.12.4.0……

### 3.3 按需求求最少 / 最多借几位（选掩码）

1. Class → host 位总数。
2. **min**：2^s ≥ 子网数（多种部门要**加起来**）。
3. **max**：2^h − 2 ≥ 最大子网的地址数 → s ≤ host 位 − h。
4. min ≤ max 才有解；「hosts 最多」选 min，「subnets 最多」选 max。

> 178.13.0.0：40 + 24 + 15 = 79 子网 → min 7；最大 220 台 → h ≥ 8 → max 8 → /23 或 /24。查表：[子网掩码速查](../final-mask-size/)。

### 3.4 某地址属于哪个子网（ANDing）

1. 找关键段和间隔。
2. **关键段 ÷ 间隔，取整 × 间隔** = 子网地址的那一段（或写出二进制 AND）。
3. Broadcast = 子网 + 间隔 − 1。

> 192.5.12.135 /27：135 ÷ 32 = 4 → 128 → 子网 192.5.12.128，bc .159，可用 .129–.158。二进制：1000 0111 AND 1110 0000 = 1000 0000。

### 3.5 🔴 给网络 + 拓扑 → 编址表（老师强调）

1. **数网络**：每个 LAN 一个 + **每条路由器之间的线一个**。
2. min / max 借位（3.3），每个 LAN 的地址数 = 主机数 + **1 个路由器接口**。
3. 列子网表，**LAN 先、链路后**依次分配。
4. 填表 **Device · Interface · IP · Mask · Default Gateway**：
   - **路由器 LAN 接口 = 第一个可用地址**（题目不会写这条规则）
   - 主机从第二个可用地址开始，**网关 = 那个路由器接口**
   - 链路两端 = 第一、第二个可用地址
   - 路由器的 Gateway 写 **N/A**；所有行同一个掩码

> 200.1.1.0，A 连 B、C、D（各有 LAN）：7 个网络 → /27。LAN A：A-E0 200.1.1.1，主机 .2，网关 .1；A–B 链路 200.1.1.128/27：A .129、B .130。

### 3.6 路由表：Initial R.T. → 完整 R.T.

1. **Initial** = 只有直连网络（来源 **C**，next hop —，hop 0），路由器之间那条线的网络两边都写。
2. **完整** = 再加远程网络（来源 **R** / S）：Interface = **本路由器朝那个方向的出口**；Next hop = 对面路由器在同一条线上的 IP；Hop = 经过几台路由器。
3. 格式（Slide 64）：Learned · Network · Hop · Interface（可以加 Next hop）。

> A–S0···S0–B，A 的 E0 / E1 接 1.0 / 2.0，B 接 4.0 / 5.0，线是 3.0：A = C 1.0 E0、C 2.0 E1、C 3.0 S0、R 4.0 S0、R 5.0 S0。

### 3.7 一个包跨多台路由器：每段 IP / MAC

1. 主机比较 Network 部分：不同网络 → 目的 MAC = **默认网关**。
2. 每一段：**IP (S, D) 不变**；**MAC (S, D) = 这一段两端的接口**（serial 段没有以太网 MAC）。
3. 每台设备发之前 ARP：主机 ARP 网关；中间路由器 ARP **next hop**；最后一台路由器 ARP **目的主机**。

| 段 | IP (S, D) | MAC (S, D) |
|---|---|---|
| PC1 → R1 | (PC1, PC3) | (MAC-PC1, MAC-R1 入口) |
| R1 → R2 | (PC1, PC3) | (MAC-R1 出口, MAC-R2 入口) |
| R2 → PC3 | (PC1, PC3) | (MAC-R2 出口, MAC-PC3) |

### 3.8 交换机 MAC 表逐帧

每一帧做两件事：**① 学 source**（新增或刷新时间戳）**② 查 destination**：广播 / 不在表 → Flood（除入口）；在别的口 → Forward；在同一个口 → Filter。
画表三列 **MAC · Port · Time stamp**；超时未刷新 → 删除。端口后接 Hub 时，一个端口可以对应多个 MAC，Hub 上其他主机也会收到帧。

### 3.9 ARP request / reply

| | MAC (S, D) | 内容 |
|---|---|---|
| Request | (MAC-1, **FF-FF-FF-FF-FF-FF**) | IP-1 / MAC-1 问：谁是 IP-3？ |
| Reply | (MAC-3, MAC-1) **单播** | IP-3 的 MAC 是 MAC-3 |

ARP 表：PC3 收到 request 时记 IP-1 → MAC-1；PC1 收到 reply 后记 IP-3 → MAC-3。

### 3.10 DHCP DORA 的地址

| 消息 | IP (S, D) | MAC (S, D) |
|---|---|---|
| DISCOVER（广播） | (0.0.0.0, 255.255.255.255) | (MAC-PC, FF-FF-FF-FF-FF-FF) |
| OFFER（单播） | (IP-server, IP-offered) | (MAC-server, MAC-PC) |
| REQUEST（广播） | (0.0.0.0, 255.255.255.255) | (MAC-PC, FF-FF-FF-FF-FF-FF) |
| ACK（单播） | (IP-server, IP-offered) | (MAC-server, MAC-PC) |

两台 server → 两个 OFFER，客户端选一个；地址池不能重叠。

### 3.11 NAT / PAT 表

1. 内网：(private, server)；出 NAT：(**public**, server)；回包：(server, public) → 换回 (server, **private**)。
2. PAT：表里写 **IP:port**，内部两台同源端口时外部端口要不同（5001、5002）。

### 3.12 三次握手（给 ISN）

| | Flags | SEQ | ACK |
|---|---|---|---|
| ① A → B | SYN | x | — |
| ② B → A | SYN, ACK | y | x + 1 |
| ③ A → B | ACK | x + 1 | y + 1 |

> ISN 10 / 20：SYN 10 → SYN-ACK 20 / 11 → ACK 11 / 21。端口：客户端动态端口 → 服务器 well-known，回包对调。

### 3.13 🔴 给 window size 画 SEQ / ACK（含丢包）

1. 握手（3.12）。第一段数据 **SEQ = ISN + 1**。
2. 一窗发 W 段：按段编号 SEQ 每段 + 1；按字节编号 SEQ 每段 + 段长度。数据段的 ACK 字段 = 对方 ISN + 1。
3. 一窗收完，接收方回**一个** ACK = **下一个要的号**；接收方的 SEQ 一直是它的 ISN + 1。
4. 丢了一段：ACK 停在丢失那一段的 SEQ（重复 ACK）→ **超时重传** → 后面先到的段已在缓冲区 → ACK 一次跳到最后。

> ISN 500 / 4000，每段 200 bytes，窗口 3，第 5 段丢：501、701、901 → ACK 1101；1101、1301 ✕、1501 → ACK 1301；重传 1301 → ACK 1701。

### 3.14 Port (S, D)：同时开两个窗口

服务器端口 = well-known（web 80）；每个客户端窗口一个不同的动态端口（49152、49153）；回包时 IP、MAC、Port 三对全部对调。

### 3.15 排错：为什么 ping 不通

| 现象 | 原因 |
|---|---|
| 同 LAN 通，跨网络全不通 | **默认网关不在本子网 / 填错**（Final Review 19） |
| 地址都对，两个 LAN 之间不通 | 路由器只有**直连路由**，缺 static route / 路由协议（A2 Q4） |
| 和同网段某台不通 | IP 重复、掩码不一致、用了 network / broadcast 地址 |
| 能用 IP 访问、不能用名字 | **DNS** |

### 3.16 RIP vs EIGRP 选路 · 拓扑变化

RIP 只数 **hop**；EIGRP 默认 **bandwidth + delay**（看整条路上最慢的一段）。链路断了：RIP 收不到更新 → 超时删除 → 改用另一条路由（metric 较大）；static route 不会自己改。

## 6. 易错清单 Common mistakes

1. 子网数用 **2^s**（不减 2），主机数用 **2^h − 2**。
2. 拓扑题数网络漏掉**路由器之间的线**。
3. 编址表漏写**路由器接口**；路由器 LAN 接口不用第一个可用地址。
4. 主机的网关写成别的子网的地址（例如串行线的地址）。
5. 路由器的 Default Gateway 填了地址（应写 N/A）。
6. 用了 network address（host 全 0）或 broadcast address（host 全 1）。
7. 掩码 255.255.255.0 一律当成 Class C 默认——先看 Class（172.16.x.x /24 是 Class B 借 8 位）。
8. /22、/23 的主机范围跨两个 octet：130.12.1.0、130.12.2.255 是合法主机。
9. 路由表远程网络写了**对面**路由器的端口，应写**本路由器**的出口。
10. 以为路由器会 flood——查不到就 **discard**；也**不转发广播**。
11. 以为交换机能隔离广播域——只有路由器能。
12. 跨网络时把目的 MAC 写成最终主机——应是**网关 / 下一跳**。
13. 每过一台路由器以为 IP 会变——**IP 不变，MAC 每跳换**（NAT 除外）。
14. ARP reply 写成广播——是**单播**。
15. DHCP 的 Request 写成单播——Discover 和 Request 都是**广播**。
16. 第一段数据 SEQ 写成 ISN——应是 **ISN + 1**。
17. ACK 写成「收到的号」——是**下一个要的号**；按字节编号要 + 段长度。
18. 一个窗口里每段都画 ACK——发完一窗才回**一个** ACK。
19. 丢段后 ACK 跳过丢失的段——期望型 ACK 只能停在**最前面缺的那一段**。
20. TFTP 当成 TCP——TFTP（69）、SNMP（161）、DHCP（67/68）都是 **UDP**；DNS 两个都用。
21. 数 MAC 位数：48 位 = 12 个 hex = 6 bytes；OUI 是前 **24** 位。
22. FCS 不对以为会请求重传——L2 只**丢弃**。
23. Private B 段写成 172.16–172.**32**——是到 **172.31**。
24. Class A 可用第一段是 1–126（127 = loopback）。
