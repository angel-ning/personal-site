## 1. 🔴 老师特别强调的两类题

<Callout type="exam" title="① 给一个 IP 网络 + 一张多路由器拓扑 → 填编址表">

题目给网络地址和拓扑（多台设备、多台路由器），要你把地址填进表里：**Device · Interface · IP Address · Subnet Mask · Default Gateway**。

**老师说：怎么给路由器以太网接口分配地址，题目里不会写——但这是要注意的点。** 按 Assignment 2 的规则做：

1. 数网络：**每个 LAN 一个 + 每条路由器之间的线一个**；
2. **min**：2^s ≥ 子网数；**max**：2^h − 2 ≥ 每个子网的地址数（**路由器接口也算一个**）；
3. **路由器 LAN 接口 = 第一个可用地址 = 该 LAN 主机的默认网关**；主机从第二个开始；链路两端用第一、第二个；路由器的网关写 N/A。

练习：[子网与编址做题](../final-subnetting/)（7 道原题、Assignment 2、两个实验）· [预测卷 B1](../final-mock/)。

</Callout>

<Callout type="exam" title="② 给 initial sequence number 和 window size → 画 SEQ / ACK">

先三次握手（SYN x → SYN-ACK y, x+1 → ACK x+1, y+1），再按窗口一批批发段，接收方每一窗回**一个期望型 ACK**（下一个要的号）；可能有一段丢失 → 重复 ACK → 超时重传。按段编号（Slide 23）还是按字节编号（ACK = SEQ + 长度）看题目。

练习：[M3 §4 时序图实验](../final-m3/#4--画图题给-isn-和-window-size画-seq--ack-️) · [预测卷 B4](../final-mock/)。

</Callout>

## 4. 核心地图：四个模块是同一个包的四层

```
一份数据从 PC1 发往另一个网络里的服务器：

M3 传输层   切段 + 端口号（谁的哪个程序）；TCP 先三次握手，SEQ / ACK + 窗口保证完整有序
     ↓
M2 网络层   源 / 目的 IP（端到端不变）；DHCP 给我 IP / 掩码 / 网关 / DNS，DNS 给对方 IP
            比较 Network 部分：同一网络 → ARP 对方；别的网络 → ARP 默认网关
            路由器：查路由表（C / static / RIP…）选出口 → 查 ARP 表找下一跳 MAC；private 地址出网靠 NAT
     ↓
M4 子网     掩码决定「Network 部分」有多长：AND 出子网地址；每个 LAN、每条路由器之间的线一个子网
     ↓
M1 链路 / 物理   帧头 = 源 / 目的 MAC（每一跳都换）+ FCS；Switch 查 MAC 表转发，Hub 全发，Router 挡广播
```

**一句话抓住整门课的前四章**：发一个包要 **6 个地址**——IP (S, D) 管终点、MAC (S, D) 管下一站、Port (S, D) 管哪个程序；所有画图题都是在问「在这一段上，这 6 个地址各是什么、是哪张表告诉你的」。

## 9. 跨模块主线（选择题和画图题都爱考）

### 9.1 五张表，别搞混

| 表 | 在哪 | 记录 | 怎么来 | 查不到 |
|---|---|---|---|---|
| **MAC / CAM 表** | Switch | MAC → Port（+ time stamp） | 看帧的**源 MAC** 自动学 | **Flood** |
| **ARP 表** | 主机、路由器 | IP → MAC | ARP request / reply | 发 ARP 广播 |
| **路由表** | Router | Network → Interface（+ next hop、metric） | 直连 C / static / 路由协议 | **Discard** |
| **NAT 表** | NAT 路由器 | Private IP(:port) ↔ Public IP(:port) | 出站时建立 | 外部主动进来的包丢弃 |
| **DNS 表** | DNS server | Name → IP | 管理员 / 缓存 | 往上一级问 |

### 9.2 三种设备

| | Hub | Switch | Router |
|---|---|---|---|
| 层 · 地址 | L1 · 无 | L2 · MAC | L3 · IP |
| 动作 | 全发 | Flood / Forward / Filter | Forward / Discard |
| 冲突域 · 广播域 | 1 · 1 | 每口 1 · 1 | 每口 1 · 每口 1 |

### 9.3 什么时候广播

ARP request · DHCPDISCOVER / DHCPREQUEST · 交换机对广播帧和未知单播的 flood。**路由器不转发广播** → ARP 只能问本网络 → 跨网络就要默认网关 → 网关必须在本网络 → 编址表里路由器 LAN 接口和主机网关必须对上。这一条链把 M1、M2、M4 串在一起。
